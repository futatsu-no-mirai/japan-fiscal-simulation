# 『2つの未来 ── 増税する日本と、しない日本』 計算コード

書籍『2つの未来』で使用した財政・生産性シミュレーションの全コードです。
本に載せたすべての表と数字は、このコードで再現できます。

**必要なもの：Python 3.9 以上と numpy だけです。**

```bash
pip install numpy
python3 v4_plan.py      # 本書の主要な表を出力
```

---

## なぜ公開しているか

本書は「政府が公表している前提を、教科書どおりの式に入れるとこうなる」という一点だけを主張しています。
その主張は、**同じ計算を他人が再現できて初めて意味を持ちます。**

数字が間違っていれば直します。前提がおかしければ変えます。
本書の第10章には、**この計画が誤りだったと判断するための条件**をあらかじめ書いてあります。

## モデルの構造

一言でいうと、**成長会計 ＋ 財政収支 ＋ 内生的な金利** を35年ぶん1年ずつ回すものです。

```
供給side  Y = A × Kt^0.15 × Ki^0.15 × (就業者 × 労働時間)^0.70
          A（生産性）は年0.5% ＋ 改革による上積み
          人口は社人研の中位推計

需要side  消費税の引き上げ・給付の増減を「前年からの変化」として需給ギャップに反映
          （2014年の消費税引き上げ実績で較正）

財政      歳入 = 税収 + 社会保険料（GDPに比例）
          歳出 = 社会保障（高齢者数に比例）+ 一般 + 地方
          利払い = 債務残高 × 実効金利

金利      市場金利 = 基準金利 + λ × (純債務/GDP − 155%)
          実効金利は市場金利へ毎年 1/9 ずつ近づく（平均残存9年）
```

### 主要な前提（すべて公表値）

| 項目 | 値 | 出典 |
|---|---|---|
| 生産性の伸び（改革なし） | 年0.5% | 内閣府「中長期の経済財政に関する試算」ベースライン |
| 人口 | 中位推計 | 国立社会保障・人口問題研究所 |

| 社会保険料 | 77兆円 | |
| 歳出 | 社会保障137／一般60／地方20兆円 | |

| 収束速度 | 年2% | Barro & Sala-i-Martin (1992) |

## 既知の弱点（本書にも同じことを書いてあります）

コードを読む前に知っておいてください。**都合の悪い点は本と同じく先に書きます。**

1. **収束速度の使い方は「類推」です。**
   2%収束則が測っているのは国と国の所得水準が近づく速さで、それを一国内の配分の歪みの解消速度に当てはめています。この当てはめを直接裏づけた実証研究はありません。**結論のほぼ全部を決めている数字が、いちばん検証されていない接合部の上に乗っています。**

2. **λ（金利の債務比率への反応）は便宜的な係数です。**
   日本では債務比率が100%から250%へ上がる間、10年債利回りはむしろ低下しました。実態は閾値を超えると跳ねる非線形だと考えられます。`regime=True` でその形も試せます。

3. **財政危機が実体経済に跳ね返る経路が入っていません。**
   だから「何もしない場合」の所得が横ばいで済んでいます。入れれば、その未来はもっと悪くなります。本書の結論を弱める方向には働きません。

4. **消費税の需要効果は、2014年の3ポイント引き上げで較正しています。**
   それを11.1ポイントの引き上げに外挿しているので、実績のあるレンジの外側です。誤差は必要税率を高くする方向に働きます。

5. **生産性の天井は製造業の推計です。**
   Hsieh–Klenow 手法自体に、測定誤差が歪みを過大評価しうるという批判があります。一方で日本の生産性の穴はサービス業にあるため、経済全体の歪みはもっと大きい可能性もあります。本書は保守側に振っています。

6. **これは「予測」ではありません。**
   35年先の水準は当たりません。読むべきはシナリオ間の差です。金融面の前提をどう動かしても必要な消費税は20.4〜21.5%に収まり、生産性の想定を動かすと17.6〜25.3%まで振れます。

## 数字が違うと思ったら

そのまま指摘してください。Issue でも、フォークして直したコードでもかまいません。
**このコードは、間違いが見つかったら直すために公開しています。**

特に確かめてほしいのは次の3点です。

- 収束速度の当てはめ（上の弱点1）に、もっと妥当なやり方があるか
- 実体経済への波及（弱点3）を入れると、結論がどう変わるか
- 社会保険料・資産課税・年金支給開始年齢を組み合わせると、必要な消費税率は何%まで下がるか
